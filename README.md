# 🎯 Jogo da Adivinhação

Um jogo simples em Python onde o jogador precisa adivinhar um número aleatório entre 1 e 100.

## 🚀 Como funciona
- O sistema gera um número aleatório.
- O jogador tenta adivinhar.
- O programa informa se o palpite é maior ou menor.
- O jogo termina quando o número é acertado.

## 🛠 Tecnologias
- Python
- Biblioteca `random`

## 🎮 Objetivo
Exercitar lógica de programação, estruturas de repetição e condicionais.
